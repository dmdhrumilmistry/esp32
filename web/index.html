🔐 p2ptun connect

Get a WireGuard config for your ESP32 p2ptun device from any phone or computer. Your key is created and kept in this browser. Relays only carry an encrypted note, and there's no server in between.

1Your key

Create a WireGuard key for this phone or computer. A passphrase is optional; it encrypts the key in this browser's storage.

Import an existing private key
Public key: paste it into the device web UI → “Authorize a client”

2Device config

After you authorize the key, the device shows a config. Paste it here (the JSON or the whole p2ptun.py join line).

3Connect

Endpoint
Scan with the WireGuard app

On the phone open WireGuard → + → Scan from QR code. The code contains your private key: only show it to your own device.

Android
  1. Install WireGuard from Google Play or F-Droid.
  2. Tap Download p2ptun.conf.
  3. In WireGuard tap + → Import from file or archive → pick the file → turn it on.
iPhone / iPad
  1. Install WireGuard from the App Store.
  2. Tap Download p2ptun.conf (it goes to Files → Downloads).
  3. In WireGuard tap + → Create from file or archive → pick the file → allow the VPN → turn it on.
Windows
  1. Install WireGuard from wireguard.com/install.
  2. Download the config, then in WireGuard click Import tunnel(s) from file → Activate.
macOS
  1. Install WireGuard from the Mac App Store.
  2. Download the config, then Import Tunnel(s) from File → Activate.
Linux
  1. sudo cp p2ptun.conf /etc/wireguard/ && sudo wg-quick up p2ptun
  2. Or use client/p2ptun.py up, which also hole-punches when the device has no router mapping.

The config stays valid until the device's public address changes. If it stops connecting, come back and get a fresh one.

Open-source: firmware, protocol and this page live in the p2ptun repository. Nothing here is sent anywhere except the encrypted knock to the relays listed in your device config.
